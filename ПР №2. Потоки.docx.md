**Практическая работа №2.**  
**Тема: Реализация многопоточного считывания и обработки файла**

**Задание №1.**  
Описание: 

* Создайте программу, которая использует потоки для параллельного чтения и обработки файла.

Условие:

1. Есть большой текстовый файл (например, "large\_text.txt").  
2. Программа должна разбить файл на N равных по размеру частей (например, 4 части).  
3. Создайте по одному потоку для каждой части файла.  
4. Каждый поток должен:  
* Читать свою часть файла.  
* Подсчитать количество встречающихся в этой части специфических символов (например, гласных букв: a, e, i, o, u).  
* Передать результат основному потоку.

Основной поток должен:

1. Запустить все потоки.  
2. Дождаться их завершения.  
3. Обобщить результаты и вывести итоговое количество гласных во всём файле.

Требования:

1. Используйте механизмы синхронизации, если потребуется совместный доступ к данным.  
2. Не используйте условные операторы (if) внутри потоков — для логики используйте циклы и арифметические операции.  
3. Реализуйте обработку ошибок при создании и запуске потоков.

**Задание №2.**

* Описание:  
  Создайте небольшое программное приложение, которое использует для параллельной обработки данных.

Условие:  
Инициализация данных:

* Создайте массив из 100 целых чисел (от 1 до 100).

Создание потоков:

* Запустите 4 потока. Каждый поток должен обрабатывать часть массива:  
* Поток 1 — числа с индекса 0–24  
* Поток 2 — числа с индекса 25–49  
* Поток 3 — числа с индекса 50–74  
* Поток 4 — числа с индекса 75–99

Обработка данных:

* Каждый поток должен считать сумму своих элементов и вывести результат.

Синхронизация:

* Основной поток должен дождаться завершения всех потоков, а затем вывести общую сумму всех элементов массива (сумма всех элементов, полученная путем объединения результатов потоков).

Требования:

* Не используйте if внутри потоковой обработки (можете использовать циклы, арифметические операции).
