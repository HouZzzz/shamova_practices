**Практическая работа №3.**  
Тема: Особенности применения блокирующих переменных в разработке приложений  
Цель работы:

* Показать принципы работы и применения различных механизмов блокировки (блокирующие переменные, lock, Monitor, Mutex, Semaphore), выявить их особенности и подходящие сценарии использования.

Задачи:

* Изучить работу блокирующих переменных на примере lock в C\#.  
* Реализовать несколько вариантов синхронизации доступа к общему ресурсу с использованием разных механизмов.  
* Сравнить поведение программ, выявить отличия по производительности и удобству.  
* Рассмотреть ошибки и проблемы, например, дедлоки.

Структура работы:  
Шаг 1: Синхронизация с lock

* Написать программу с несколькими потоками, которые используют общий счётчик.  
* Реализовать обновление счётчика с использованием конструкции lock.  
* Вывести итоговое значение счётчика и убедиться в корректности результата.

Шаг 2: Использование Monitor

* Повторить задачу из шага 1 используя Monitor.Enter и Monitor.Exit.  
* Объяснить отличие от lock.

Шаг 3: Использование Mutex

* Модифицировать программу, синхронизируя доступ при помощи Mutex.  
* Продемонстрировать, что Mutex может работать между процессами (по желанию).

Шаг 4: Использование Semaphore

* Написать программу, где ограниченное число потоков одновременно могут получить доступ к ресурсу.  
* Использовать Semaphore для контроля количества одновременных обращений (например, максимум 2).

Шаг 5: Демонстрация дедлока

* Создать пример с двумя потоками и двумя блокировками, захватываемыми в разном порядке.  
* Показать возможную ситуацию дедлока (зависания).
